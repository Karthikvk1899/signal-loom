# Security policy

Signal Loom is a reference implementation. Do not use it to authorize users or store secrets in feature bundles. Read docs/THREAT_MODEL.md and docs/OPERATIONS.md before adapting it.

For a suspected vulnerability, do not post credentials or exploit details in a public issue. Contact the repository owner through an available private GitHub channel, or ask in a public issue for a private reporting route without disclosing details. GitHub private vulnerability reporting may not be enabled. No response-time guarantee or security certification is implied.

Include affected commit, minimal reproduction, expected/actual boundary, and impact. Current development targets the main branch; older revisions have no support promise.
